# Requirements

Every testable statement in `SPEC.md`, one row each. IDs are stable; never renumber, only
append or mark a row `withdrawn` (keep the row). Tests cite an ID with `@req R-AREA-NN`.
`pnpm spec:check` (`scripts/spec-check.mjs`) fails when a row has no test, cites a missing
section, or a test cites an unknown ID. Columns: ID | requirement | spec | verified by.
