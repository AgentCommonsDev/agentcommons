# Site assets

`apps/dashboard/public/logo.png` is the AgentCommons mark, generated with the built-in
image generation tool on 2026-09-07 at the user's request. It is used for the site
header and PNG favicon. The source has a transparent background; dark mode can invert
the ink with CSS without changing the asset.

Generation prompt:

> Use case: logo-brand. Asset type: production square app logo for the AgentCommons site header and browser favicon. Create one exceptionally simple, distinctive geometric symbol suggesting several coding-agent session paths joining a shared archive: a compact abstract capital A formed from two sturdy interlocking bracket-like shapes with one open central negative-space channel. Minimalist, precise, calm, balanced, flat vector-like silhouette; bold enough to read at 16 pixels. One near-black ink color on a genuinely transparent background, no opaque tile. Centered mark occupying 80 percent of the square with even padding. Straight clean edges, subtle rounded corners, no hairlines. No lettering, no wordmark, no gradients, no shadows, no texture, no robot, brain, sparkles, or network-of-dots illustration. Return a single finished logo mark, no mockup or variation sheet.
