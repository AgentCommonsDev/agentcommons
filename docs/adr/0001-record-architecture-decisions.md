# 0001. Record architecture decisions

Date: 2026-09-07 · Status: accepted

We record every decision that a future contributor (human or agent) might want to reverse,
in this directory, one file each, with the alternatives considered. The spec references ADRs;
ADRs do not restate the spec.

Format: title, date, status, context, decision, alternatives, consequences. Keep each under a
page. Supersede rather than edit: add a new ADR and mark the old one superseded.
